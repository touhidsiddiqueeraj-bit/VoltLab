Motor control circuit simulator

Wire it. Run it. Break it.
Let an agent drive it.

VoltLab simulates electromechanical motor-control circuits — DOL starters, interlocks, reversing starters, a 10-story relay elevator, an electric vehicle drive — with a real per-tick electrical solver and IEC-style schematics. Drive them like machines: accelerator & brake pedals, a VFD with frequency ramps, e-stop mushrooms, car operating panels. And because it speaks MCP, an LLM agent can build, wire, fault and document every circuit for you.

Try: hold S1 on the schematic — the contactor picks up and the motor spins (release: the seal-in keeps it running). Toggle breaker Q1 by clicking it. Pick reversing-starter and watch the interlock. New in v1.3: load vehicle-drive and drag the accelerator pedal in the console — or slam the e-stop and watch the drive ramp down; take elevator-cop for a ride from its car operating panel.

Why VoltLab

A trainer bench, a drawing office and an agent playground

🔌Real physics

Per-tick union-find netlists and phase propagation: 6× FLC inrush, class-10 thermal trip curves, single-phasing, coast-down, fuse blowing — plus VFDs with synthesized rotating fields, frequency ramps and phase-sequence motor direction.

🕹Operator console

The bottom panel grows real controls for whatever the circuit contains: drag-able accelerator/brake pedals, a twist-release e-stop mushroom, drive Hz + direction readouts, a 7-segment floor indicator and car-call grids.

📐IEC-style schematics

23 device types drawn as proper IEC symbols, phase-colored live wires, terminal-level wiring, zoom from 25–300 %, inspector and event log.

🤖MCP agent layer

29 tools over stdio JSON-RPC (or plain HTTP): agents build, wire, fault, reset, fast-forward, drive pedals and call floors — the full test suite is an agent session.

📄Self-documenting exports

Any circuit exports as an IEC 61082-1-style multi-sheet PDF drawing set (zone grids, title blocks, sheet index) and a scripted 720p demo video.

📱Desktop, Android, offline

Signed installers for Windows, macOS and Linux plus an Android APK with the full offline editor — or zero-install right in this browser. Server, simulator and MCP bridge are pure Node stdlib.

New in v1.3 — the operator round

Drive it like a machine

Seven new electrical devices — a variable frequency drive, accelerator and brake pedals, an e-stop mushroom, a 3-position selector, a car-call panel and a floor indicator — turn schematics into things you operate. Nothing here is decoration: the pedal is a potentiometer feeding the VFD's analog reference, the brake's NC contact cuts the drive enable while its mechanical side drags the motor, and car calls latch through real relay logic.

Run the full app

Quick start

git clone https://github.com/touhidsiddiqueeraj-bit/VoltLab.git
cd voltlab
npm install            # once — installs Electron only

npm run serve          # browser mode → http://127.0.0.1:8123
npm start              # or the Electron desktop window
npm test               # 57 headless tests: engine + circuits + features + MCP end-to-end

Agents connect over MCP — point any client at mcp/server.mjs and it gets the full 29-tool catalog (reference).
