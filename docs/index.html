Motor control circuit simulator

Wire it. Run it. Break it.
Let an agent drive it.

VoltLab simulates electromechanical motor-control circuits — DOL starters, interlocks, timers, reversing starters, even a 10-story relay elevator — with a real per-tick electrical solver and IEC-style schematics. And because it speaks MCP, an LLM agent can build, wire, fault and document every circuit for you.

This is the real simulator

Not a video, not a mock-up: the page below runs the actual sim/engine.js solver in your browser — the same code the desktop app and the MCP agents drive.

Try: hold S1 on the schematic — the contactor picks up and the motor spins (release: the seal-in keeps it running). Toggle breaker Q1 by clicking it. Pick reversing-starter from the dropdown and watch the interlock. When the thermal overload KK1 trips (⏩ 5s after a stall), click its red RESET.

Why VoltLab

A trainer bench, a drawing office and an agent playground

🔌Real physics

Per-tick union-find netlists and phase propagation: 6× FLC inrush, class-10 thermal trip curves, single-phasing, coast-down, fuse blowing — not a canned animation.

📐IEC-style schematics

16 device types drawn as proper IEC symbols, phase-colored live wires, terminal-level wiring, zoom from 25–300 %, inspector and event log.

🤖MCP agent layer

26 tools over stdio JSON-RPC (or plain HTTP): agents build, wire, fault, reset, fast-forward and inspect circuits — the full test suite is an agent session.

📄Self-documenting exports

Any circuit exports as an IEC 61082-1-style multi-sheet PDF drawing set (zone grids, title blocks, sheet index) and a scripted 720p demo video.

🎓Learn as you go

An 11-step interactive tutorial with action gates, five worked example circuits with behavior tests, light and dark themes.

📦Zero runtime deps

Server, simulator and MCP bridge are pure Node stdlib. Electron is the only dev dependency. npm run serve and you're running.

Quick start

git clone https://github.com/touhidsiddiqueeraj-bit/VoltLab.git
cd voltlab
npm install            # once — installs Electron only

npm run serve          # browser mode → http://127.0.0.1:8123
npm start              # or the Electron desktop window
npm test               # 31 headless tests: engine + circuits + MCP end-to-end

Agents connect over MCP — point any client at mcp/server.mjs and it gets the full 26-tool catalog (reference).
